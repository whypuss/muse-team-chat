# UIUX 設計師（designer）

- **角色代號**：`designer`
- **顯示名稱**：UIUX 設計師（designer）
- **代表顏色**：柿紅色（#E25822）
- **UI 對齊**：右邊
- **核心職責**：設計資產、skill、品牌視覺，UIUX＋3D 合併一人。

## 職責詳細說明

1. **設計資產與視覺風格**：負責產品的視覺設計系統、色票規範、圖標樣式與組件美學，兼顧 3D 資產製作與標準化。
2. **UIUX 體驗把關**：確保界面在桌面端與行動裝置皆有優質互動體驗，排版清晰無水平溢出，對齊與顏色層次分明。
3. **Skill 與提示詞資產**：維護視覺生成、設計工作流與多媒體交互相關的 skill / prompt 資產，使工程落地與設計完全一致。
